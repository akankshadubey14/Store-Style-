# Style Store Annual Report

## 📌 Project Overview
This project presents an in-depth sales analysis of **Style Store** for the year using **Microsoft Excel**. The dashboard provides insights into sales trends, customer demographics, order status, and platform performance to help make data-driven decisions.

---

## 🛠️ Tools & Technologies Used
- **Microsoft Excel** (Pivot Tables, Charts, Slicers, Data Visualization)
- **Data Cleaning & Formatting**
- **Dashboard Design & Analysis**

---

## 📊 Key Insights

1. **Orders vs Sales** 📈
   - Sales peaked around **March and April**, with a gradual decline toward year-end.
   - Monthly revenue fluctuated between **1.3M to 1.9M**.

2. **Customer Demographics** 👥
   - **64% of purchases** were made by **women**, while **36%** were from **men**.
   - Age group analysis showed that **adults (33.16%)** contributed the highest number of orders.

3. **Order Status & Fulfillment** 🚚
   - **92% of orders** were successfully delivered, while **3% were returned**, **3% were canceled**, and **2% were refunded.

4. **Top 5 Performing States** 🏆
   - The highest sales came from **Maharashtra (2.76M), Karnataka (2.45M), Uttar Pradesh (1.95M), Telangana (1.56M), and Tamil Nadu (1.53M).**

5. **Sales Channel Performance** 🏪
   - **Amazon (35%) and Flipkart (22%)** were the top-selling platforms.
   - **Myntra (23%) also contributed significantly, followed by Ajio (6%) and others.**
